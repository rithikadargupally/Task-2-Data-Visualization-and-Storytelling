# Sales Performance Dashboard (Power BI)

## Project Overview

This project analyzes sales performance using Power BI. The dashboard provides insights into sales, profit, quantity sold, category performance, regional performance, and product profitability.

## Dataset

Sample Superstore Dataset

## Tools Used

- Power BI
- Excel
- CSV Dataset

## Dashboard Preview

![Dashboard](Screenshot%202026-06-01%20182428.png)

## Key Metrics

- Total Sales: 2.30M
- Total Profit: 286.40K
- Total Quantity Sold: 38K

## Key Insights

### Overall Business Performance

The company generated 2.30M in sales, 286.40K in profit, and sold 38K units.

### Category Analysis

- Technology generated the highest sales.
- Technology generated the highest profit.
- Furniture showed lower profitability.

### Regional Analysis

- West region recorded the highest sales.
- West region generated the highest profit.
- South region recorded the lowest sales.

### Product Analysis

- Copiers generated the highest profit.
- Phones and Accessories also performed strongly.
- Bookcases, Supplies, and Fasteners generated relatively low profit.

## Conclusion

Technology products and the West region are the primary drivers of business growth. Focusing on high-performing sub-categories while improving weaker segments can further increase profitability.
